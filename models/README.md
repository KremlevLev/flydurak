# Checkpoints

Large checkpoints are not tracked by Git. Running `flydurak` downloads the
published checkpoint automatically when this directory is empty.

For the current demo, copy or download:

```text
durak-fast-plastic-r32.best.pt
```

into this directory, then follow the browser command in the project README.

Release URL: `https://github.com/KremlevLev/flydurak/releases/download/v0.1.0/durak-fast-plastic-r32.best.pt`
